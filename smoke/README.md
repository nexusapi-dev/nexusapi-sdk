# Смоук-тест против живого API

Юнит-тесты SDK работают на подменённых ответах. Этот тест проверяет текущий код
репозитория против настоящего API — перед выпуском или после изменений на
сервере.

```bash
export NEXUSAPI_API_KEY=...   # ключ из panel.nexusapi.dev; в скрипты он не печатается

# Python — из корня репозитория
pip install httpx
python smoke/python_smoke.py          # бесплатно
python smoke/python_smoke.py --paid   # + платные проверки, около 1 ₽

# Node
(cd node && npm ci && npm run build)
node smoke/node_smoke.mjs
node smoke/node_smoke.mjs --paid
```

| Проверка | Стоимость |
|---|---|
| Каталог моделей, ключ и `/v1/models` | бесплатно |
| Секрет вебхуков совпадает с вычисленным в SDK | бесплатно |
| 404 на несуществующую задачу и модель, в ошибке есть `request_id` | бесплатно |
| Чат `gpt-6-luna`, обычный ответ и стрим (`--paid`) | доли копейки |
| Картинка `nano-banana` и повтор с тем же ключом даёт ту же задачу (`--paid`) | 0,8 ₽ |

Другой адрес API — переменная `NEXUSAPI_BASE_URL`. Код выхода 0 — все
проверки прошли.
