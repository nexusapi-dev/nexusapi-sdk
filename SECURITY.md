# Security

Нашли уязвимость в SDK или в API NexusAPI — не открывайте публичный issue.
Сообщите приватно:

- через **Security → Report a vulnerability** в этом репозитории
  (GitHub private vulnerability reporting), или
- на support@nexusapi.dev с темой «Security».

Опишите, как воспроизвести, и что затронуто. Мы ответим и сообщим, когда
исправление выйдет.

Никогда не публикуйте свой API-ключ NexusAPI в issue, логах или примерах кода.
Если ключ утёк — отзовите его в [panel.nexusapi.dev](https://panel.nexusapi.dev)
и создайте новый.
